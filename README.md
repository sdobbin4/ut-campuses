# One University, Five Campuses

A revised version of the ArcGIS StoryMap [UT Campuses](https://storymaps.arcgis.com/stories/6adf22b80945412ab673669125c3f062). It is a static site, hosted on GitHub Pages, that maps the five University of Tennessee System campuses and gives their history and Fall 2025 enrollment.

It is a single `index.html` built with [Leaflet](https://leafletjs.com/) and OpenStreetMap tiles. There is no build step.

Data sources are listed on the page.
